# Security policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of opening a
public issue. If that channel is unavailable, contact `mathweuzz@gmail.com` with
the subject `RDD2022 CPU baseline security report`.

Include affected files or versions, reproduction steps, potential impact, and
any suggested mitigation. Please avoid sharing credentials, private datasets,
or personally identifying imagery. Acknowledgment is targeted within seven days.

Model accuracy failures and research limitations are not software security
vulnerabilities; report those through the reproducibility issue template.
