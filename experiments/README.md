# Experiments

## CPU integration smoke test

The first milestone validates the complete data-to-checkpoint path without
claiming scientific performance:

```bash
PYTHONPATH=.deps python3 experiments/train_torchvision_baseline.py
```

The default run uses RetinaNet-ResNet50-FPN-v2 with random initialization, eight
selected images, one optimizer step, COCO evaluation on eight validation images,
and CPU execution when CUDA is unavailable. The diagnostic input scale is
320--640 pixels; scientific runs must record and freeze their selected scale.

The scientific CPU run uses an equal-domain subset generated by
`build_cpu_yolo_protocol.py`, official COCO-pretrained YOLO11n weights, and the
fixed budget described in `EXPERIMENT_PROTOCOL.md`. The untouched internal test
is evaluated once with `evaluate_yolo_checkpoint.py`.

The final low-memory evaluation uses one pathname per model call. Do not pass
the complete image list to the Ultralytics loader on this host:

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
PYTHONPATH=.deps python experiments/evaluate_yolo_checkpoint.py \
  --model outputs/yolo11n_joint_cpu_final_seed2026/weights/last.pt \
  --split test \
  --output outputs/yolo11n_joint_cpu_final_seed2026/test_evaluation \
  --imgsz 320 --batch 1 --workers 0 --threads 1
```

This final run completed in 162.1 seconds with 1.33 GiB peak RSS. Its test
metrics are stored in `test_evaluation/evaluation.json`.

## CPU-budgeted protocol

```bash
python experiments/build_cpu_yolo_protocol.py \
  --train-images 2800 --seed 2026 --output outputs/cpu_protocol_2800
```

The joint list contains 400 images from each of the seven acquisition domains
and preserves each domain's negative-image rate. The frozen primary run uses
10 epochs, 320-pixel inputs, batch size 8, AdamW, and seed 2026 on CPU. All
paths and realized class/domain counts are recorded in `protocol.json`.

Reproduce the frozen training run after building that protocol:

```bash
PYTHONPATH=.deps python experiments/train_yolo_cpu.py
```

The script exposes overrides through `--help`, but its defaults encode the
published optimizer, augmentation, resolution, batch, epoch, seed, and
final-checkpoint policy. For low-memory inference on arbitrary images, use:

```bash
PYTHONPATH=.deps python experiments/predict.py \
  --model path/to/checkpoint.pt --source path/to/image-or-directory
```

## Archived RT-DETR candidate diagnostic

The transformer comparison has a separate runner so the qualified TorchVision
baseline remains unchanged:

```bash
PYTHONPATH=.deps python3 experiments/train_rtdetr_baseline.py \
  --output outputs/rtdetr_smoke --max-train-batches 1 --max-val-images 2
```

This path was qualified but not promoted after the project adopted a CPU-only
scope. Its smoke-test values remain diagnostic and are not paper results.
